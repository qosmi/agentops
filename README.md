# AgentOps

Production-oriented agentic business investigation system.

AgentOps investigates operational business questions using structured
data, specialized AI agents, deterministic tools, evidence verification,
evaluation, guardrails, and human approval.

## Status

🚧 Early development

## Architecture

The system will eventually include:

- agent orchestration
- typed tool calling
- data pipelines
- evaluation
- guardrails
- observability
- human approval
- cloud deployment
- infrastructure as code
- CI/CD
